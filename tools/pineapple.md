## Description ##
The Wi-Fi Pineapple NANO is a pocket-sized, highly automated wireless network auditing tool. Developed by Hak5, it acts as a dedicated portable platform designed specifically for wireless penetration testing, reconnaissance, and executing advanced Man-in-the-Middle (MitM) attacks against Wi-Fi networks.

## Usage ##
The NANO uses dual dedicated 2.4 GHz wireless radios and a custom Linux-based operating system to automate complex wireless exploitation:
The PineAP Suite: 
    A patented, built-in suite of tools that automatically scans the airwaves and mimics preferred wireless networks to trick client devices into connecting.
Dual Radio Routing: 
    One internal radio actively scans and broadcasts rogue access points, while the second radio handles internet backend passthrough or tactical sniffing.
Precision Targeting Filters: 
    Built-in parameters that restrict attacks to specific target MAC addresses or network SSIDs, ensuring compliance with audit scopes and preventing collateral disruption.
Web UI Dashboard: 
    A clean, graphical web panel accessible from any browser (on a laptop or smartphone) that allows users to monitor traffic and launch attacks with a single click.

## Attacks ##
1. Wireless Auditing 
    Network administrators use it to map wireless airspace, discover rogue access points, and test the resilience of corporate networks.
2. Evil Twin Attacks
    The device broadcasts familiar network names (SSIDs) that nearby phones or laptops have previously connected to, tricking these devices into auto-connecting to the Pineapple instead of the legitimate network.
3. Man-in-the-Middle (MitM) Interception
    Once a device is tricked into connecting, the Pineapple sits between the user and the internet, allowing the tester to inspect passing traffic.Credential Harvesting: It can deploy custom web pages—such as a fake airport or cafe login screen—to trick users into voluntarily entering their usernames and passwords.
