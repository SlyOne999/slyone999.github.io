## Description ##
The Shark Jack is a pocket-sized, ultra-portable network attack tool designed for rapid, physical penetration testing of wired Ethernet networks. Developed by Hak5, it is shaped like an oversized Ethernet connector and is engineered to perform quick "hot-plug" reconnaissance and network exploitation the moment it is plugged directly into a wall jack or switch port.🛠️ Core CapabilitiesThe device is built to slip into a pocket and execute automated tasks silently without requiring a laptop on-site:Standalone Battery Power: Features an integrated rechargeable battery, allowing it to boot up, run scripts, and harvest data entirely on its own power.Automated Payload Execution: Utilises a simple switch to toggle between "Arming Mode" (to program scripts) and "Attack Mode" (to execute scripts immediately upon plugging into an active Ethernet port).Linux-Based Architecture: Runs a lightweight Linux operating system (OpenWrt), giving it access to standard, powerful network scanning command tools.RGB LED Indicator: Uses a single multi-colour LED to communicate its current status to the operator, flashing distinct sequences for booting, successful scanning, payload completion, or errors.📡 Primary Types of Attacks1. Rapid Network ReconnaissanceNetwork Mapping (Nmap Scans): Automatically scanning the local network segment the instant it is plugged in. It maps out active IP addresses, discovers connected devices (like servers, printers, and workstations), and identifies open, vulnerable ports.DHCP Sniffing & Spoofing: Intercepting the network's automated IP assignment process to identify critical network gateway addresses and DNS server configurations.2. Credential & Hash HarvestingResponder Attacks: Running tools that listen for local network broadcast name resolutions (like LLMNR or NetBIOS). When a nearby Windows machine attempts to look up a network asset, the Shark Jack answers, tricking the machine into sending over its cryptographic password hashes.3. Endpoint & Port SpoofingMAC Address Cloning: Copying the media access control (MAC) address of a legitimate corporate device (like a network printer or VoIP desk phone). This bypasses Network Access Control (NAC) security systems that block unapproved devices from connecting to the office network.4. Establishing Remote AccessReverse Shell Deployment: If the local network has an open connection out to the public internet, the Shark Jack can automatically dial out to a remote cloud server controlled by the attacker, opening an encrypted backdoor tunnel into the target's internal infrastructure.
