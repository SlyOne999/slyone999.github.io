## Description ##
The Packet Squirrel is a stealthy, pocket-sized hardware Ethernet multi-tool designed for advanced network administration, penetration testing, and covert remote access. Developed by Hak5, it sits silently inline between a target computer and a network switch, serving as a powerful platform for intercepting network packets, spoofing traffic, and establishing permanent backdoors.🛠️ Core CapabilitiesThe device is engineered to remain physically and digitally invisible while routing full gigabit network traffic through its hardware engine:Inline Interception: Features dual Ethernet ports (In and Out), allowing it to sit between a target device (like a VoIP phone, workstation, or server) and the network drop without interrupting connectivity.Covert Form Factor: Exceptionally small and lightweight, looking like an innocent network adapter or a small USB hub that blends into cable clutter behind a desk.Simple Payload Switch: Features a physical 4-way switch on the chassis, allowing operators to boot the device into a dedicated setup mode or select from three pre-loaded automated scripts.Linux Environment: Powered by a lightweight Linux system (OpenWrt) that fully supports standard networking utilities, bash scripting, and complex programming languages.📡 Primary Types of Attacks1. Passive & Active Packet SniffingFull Network Tap (tcpdump): Silently capturing all data passing through the cable and saving it directly to an attached USB flash drive as standard PCAP files. Attackers extract these files later to read unencrypted emails, web traffic, and sensitive data.VoIP Call Interception: Sitting inline behind an office desk phone to intercept unencrypted SIP audio packets, allowing an auditor to reconstruct and listen to private phone conversations.2. Stealth Man-in-the-Middle (MitM)DNS Spoofing: Overriding local domain requests passing through the wire. When the victim types their company intranet address, the Packet Squirrel alters the destination on the fly, pointing them to an attacker-hosted fake website.Traffic Redirection: Secretly copying all network packets and mirroring them over the air or web to an off-site listening post without alerting the user or changing network speeds.3. Permanent Remote Access & Persistent BackdoorsSecure VPN/SSH Tunnels: Dialing out to an external cloud server controlled by the attacker using OpenVPN or SSH. This establishes a permanent, encrypted gateway back into the victim's internal network that easily bypasses incoming corporate firewalls.Command and Control (C2) Integration: Connecting natively to centralized management tools, allowing teams to remotely trigger payloads or execute network terminal commands from anywhere in the world.4. Bypassing Network ProtectionsMAC Address Clone-Through: Copying the identity of the computer plugged into it. Network Access Control (NAC) systems view the connection as a single, legitimate approved computer, completely hiding the Packet Squirrel's presence.
