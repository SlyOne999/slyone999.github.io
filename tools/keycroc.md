## Description ##
The Key Croc is an advanced, hardware-based keyboard man-in-the-middle (MitM) tool designed for physical penetration testing, social engineering, and rapid credential harvesting. Developed by Hak5, it sits inline between a target's physical USB keyboard and their computer, serving as a weaponized keylogger that actively alters typed text in real time.🛠️ Core CapabilitiesThe device looks like an innocent USB adapter or thumb drive, but it houses an entire Linux system that intercepts and manipulates raw keyboard data before it reaches the computer:Inline Keylogging: Intercepts every single stroke typed on a physical keyboard, secretly caching passwords, messages, and terminal commands to its internal memory.Pattern Matching & Triggers: Monitors live typing for specific keywords (like "password", "bank", or a corporate username format) to instantly trigger automated hacking payloads.Keystroke Injection (BadUSB): Not only records keys but can inject its own typed commands at hyper-speed, executing stealth scripts the moment a victim types a trigger word.Onboard Wi-Fi Access: Features built-in wireless connectivity, allowing an attacker to connect to the device from a smartphone or laptop to view live typing or download logged keystrokes from a distance.Cloud C2 Integration: Connects to central web management platforms, allowing a remote hacker to monitor a target's live keyboard input from anywhere in the world over the internet.📡 Primary Types of Attacks1. Real-Time Credential HarvestingTargeted Password Sniffing: The Key Croc can be programmed to ignore standard typing but instantly alert the attacker via Wi-Fi whenever the user types their email address followed by a password sequence, isolating high-value corporate credentials.2. Interactive Payload InfiltrationTrigger-Based Exploitation: Unlike traditional USB Rubber Duckies that run payloads immediately upon being plugged in, the Key Croc can wait silently for days. When it detects the user has opened a command terminal and typed a specific trigger phrase, it takes over the keyboard to download malware or open a backdoor backdoor.3. Data Exfiltration via TextCovert Exfiltration: It can be configured to watch for specific sensitive strings on the machine. If an authorized user logs into a sensitive server, the Key Croc records the session access codes and securely uploads them over its independent Wi-Fi link.4. Stealth Physical DeploymentThe "Cable Adapter" Disguise: Shaped like a generic USB adapter, it plugs into the back of a desktop tower or a docking station. It blends into corporate office environments perfectly, as IT departments frequently use similar dongles for wireless mice or keyboard receivers.
